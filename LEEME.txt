ESTUDIO JURÍDICO MAGALLANES - MONTERO (M&M)
Proyecto Final - Algoritmos y Estructura de Datos

CÓMO ABRIRLO EN APACHE NETBEANS
1. Descomprime el ZIP.
2. NetBeans > File > Open Project... > selecciona la carpeta EstudioJuridicoMM.
3. Clic derecho en el proyecto > Run (o F6). La clase principal es ui.MainApp.
   (Requiere JDK 17 o superior.)

DATOS PRECARGADOS
La primera vez el sistema carga datos de prueba (paquete persistencia, clase DatosIniciales):
 - 5 expedientes abiertos (EXP-2026-0001 a EXP-2026-0005) con su historial de movimientos.
 - 10 clientes y contrapartes en el árbol por DNI/RUC.
 - 1 ficha en evaluación (SOL-0008, Roberto Flores).
 - 5 solicitudes en la cola (SOL-0009 a SOL-0013).
Al salir se guarda todo en el archivo datos_estudio_mm.dat (en la carpeta del proyecto).
Para volver a los datos de prueba: Menú principal > opción 6.

PRUEBAS
 Abrir pruebas/PruebasSistema.java y ejecutar con Shift+F6. Muestra PASO/FALLO por cada
 verificación (orden de atención, historial, guardar/cargar, restaurar, árbol, tabla hash,
 lista enlazada, merge sort y conflicto de interés). No modifica los datos del usuario.

ESTRUCTURAS (paquete estructuras, implementación propia, sin java.util)
 - Cola<T>  : solicitudes pendientes y fichas en evaluación (FIFO).
 - Pila<T>  : historial del expediente (cima = último movimiento) y pila de anulados (LIFO).
 - ListaEnlazada<T> : expedientes de cada cliente y cubetas de la tabla hash.
 - TablaHash<K,V>   : búsqueda de cualquier solicitud por código (Solicitudes > opción 5).
 - Ordenamiento     : merge sort recursivo para listar expedientes por criterio (Búsqueda > opción 5).
 - ArbolBinarioBusqueda<K,V> : expedientes por código y clientes/contrapartes por DNI/RUC.
   Sigue la clase Arbol de la sesión de Árbol Binario (agregar, buscar, eliminar,
   encontrarMinimo, mostrarElementos / recorrerEnOrden).

NOMBRES DE MÉTODOS (iguales a los PDF de las Semanas 11 y 12)
 - Pila: push, pop, peek, estaVacia, cantidadElementos, mostrarPila, limpiarPila.
 - Cola: agregar, poll, peek, estaVacia, cantidadElementos, mostrarCola, limpiarCola.


SI ALGO NO SE VE / AVISOS AL COMPILAR
 - Ejecutar con F6 (Run Project), no con Shift+F6 sobre otro archivo.
 - Los menús siempre aparecen delante de las demás ventanas y en la barra de tareas
   como "Estudio Jurídico M&M". Para desactivarlo: ui/Dialogos.java, SIEMPRE_ADELANTE = false.
 - El aviso "location of system modules is not set in conjunction with -source 17"
   NO es un error: el proyecto está en Java 17 y el JDK instalado es más nuevo.
   Para quitarlo: clic derecho al proyecto > Properties > Sources >
   Source/Binary Format = versión de su JDK (21 o 25) > OK > Clean and Build.

DOS VERSIONES (mismo código)
 - ui/Tema.java, MOSTRAR_TEMAS = true  : la interfaz indica la estructura usada
   (Cola, Pila, Árbol, cima, recorrido en orden...). Para la sustentación técnica.
 - ui/Tema.java, MOSTRAR_TEMAS = false : interfaz limpia para la presentación.
